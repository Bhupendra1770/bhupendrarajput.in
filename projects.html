Cue — MCP Voice Agent

Personal Project · Voice AI · MCP
Cue
Voice-Controlled Software Automation Agent

A voice and text AI agent that controls any registered software via natural language, using a custom REST-to-MCP bridge, multi-software tool chaining, and a destructive-action confirmation gate. Also the foundation of my MCA final year project, "Voice-Driven Software Automation Using MCP-Integrated AI Agent."

  • Custom REST-to-MCP bridge pattern with OpenAPI auto-import for tool registration
  • Multi-software tool chaining with a bounded reasoning loop (max 5 steps)
  • Groq Llama 3.3-70B for reasoning, OpenAI Realtime API for low-latency server-side voice capture
  • Tenant-ready data model with a destructive-action confirmation gate for safety

PrintMe — Kiosk SaaS

Founder · Subscription SaaS
PrintMe
Self-Serve Print Kiosk for Copy Centers

A fully on-premise SaaS product for copy centers across India: customers scan a QR code, upload a PDF, pay via UPI, and the shop's own PC silently prints the file — no cloud server, no customer data leaving the shop's network.

  • FastAPI running locally on the shop's PC, exposed publicly via its own Cloudflare Tunnel subdomain
  • Razorpay integration where payments flow directly from customer to shop owner — no funds pass through my accounts
  • SumatraPDF-based silent printing, triggered the instant a Razorpay webhook confirms payment
  • Distributed as a Windows .exe installer (PyInstaller); one-time licensing model similar to Indian POS software
